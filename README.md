# <img src="https://idkwctu.vercel.app/android-chrome-512x512.png" width="24" style="vertical-align: middle;" /> I Don't Know What Colors To Use (IDKWCTU)

A simple website for experimenting with colors and seeing how they work together. Change colors, preview your layout, and find combinations that look good.

**Live:** https://idkwctu.vercel.app/

## Features

- Live color preview
- Light and dark mode
- Customizable everything!
- Copyable CSS variables
- Font selection

## Running Locally

```bash
# Clone the repository
git clone https://github.com/dulakgg/IDKWCTU.git

# Navigate into the project
cd IDKWCTU

# Install dependencies
npm install

# Start the development server
npm run dev
```
