# \<img src="[https://idkwctu.vercel.app/android-chrome-512x512.png](https://idkwctu.vercel.app/android-chrome-512x512.png)" width="24" style="vertical-align: middle;" /> I Don't Know What Colors To Use (IDKWCTU)

A simple, interactive website for experimenting with colors and discovering combinations that work well together.

Customize your website's appearance in real time, experiment with different color palettes, preview your changes, and make sure your colors remain accessible.

**Live Website:** [https://idkwctu.vercel.app/](https://idkwctu.vercel.app/)

## Features

### Color Customization

- **Live Color Preview:** See your color changes instantly without refreshing the page.
- **Fully Customizable:** Adjust backgrounds, surfaces, text, accents, and other interface colors.
- **Light & Dark Mode:** Design and experiment with both light and dark themes.
- **Custom Color Picker:** Pick colors visually or enter specific HEX values.
- **Font Selection:** Experiment with different fonts to find the right typography for your design.

### Accessibility & Contrast Checker

- **Automatic Contrast Checking:** Automatically analyze the contrast between foreground and background colors.
- **WCAG Standards:** Check color combinations against WCAG 2.1 accessibility guidelines.
- **AA & AAA Compliance:** Determine whether text meets the required contrast ratios.
- **Contrast Ratios:** Get precise contrast ratio calculations for selected color combinations.
- **Live Cursor Inspector:** Inspect elements underneath your cursor and analyze their foreground and background colors.
- **Accessibility Indicators:** Quickly identify whether a color combination passes or fails accessibility requirements.

### Export & Convenience

- **Copyable CSS Variables:** Export your customized theme as CSS variables.
- **Theme Persistence:** Keep your customizations when revisiting the website.
- **Real-Time Updates:** All changes are reflected immediately in the preview.

## Running Locally

You can run IDKWCTU locally by following these steps.

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/dulakgg/IDKWCTU.git
```

**2. Navigate into the project directory**

```bash
cd IDKWCTU
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Vite will start the development server. Open the local URL displayed in your terminal to access the website.

### Production Build

To create an optimized production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
